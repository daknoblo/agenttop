# Security

## Supported version

The maintained version is the current `main` branch. Fixes are made there;
separate backport branches are not maintained.

## Reporting a security-sensitive issue

If **Report a vulnerability** is available in the repository's **Security** tab,
use that private reporting form.

Otherwise, open an issue titled **Security contact request**, without exploit
details or sensitive attachments. The maintainer can then arrange a private
reporting channel before you share the details.

Once a private channel is available, useful information includes the affected
version, impact and a minimal reproduction. Please avoid posting sensitive
reports in a public bug report.

Reports are handled on a best-effort basis; this personal project does not offer
a response-time guarantee.
